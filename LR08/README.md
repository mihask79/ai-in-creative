## Условия эксперимента

Фактическая основная серия:

| Метрика | A: β=1 | s(A) | B: β=8 | Δ=B−A | 2s | По допуску |
| --- | ---: | ---: | ---: | ---: | --- | --- |
| Реконструкция, дБ | 26,3679 | 0,6200 | 22,4103 | −3,9576 | да | ухудшение |
| Интерполяция, дБ | 22,6480 | 0,3938 | 21,9885 | −0,6595 | нет | нейтрально |
| Сэмплы, дБ | 23,3030 | 0,5351 | 23,2587 | −0,0443 | нет | нейтрально |
| R² факторов | 0,90224 | 0,01924 | 0,81831 | −0,08392 | да | ухудшение |

Число активных осей A по seed: **6, 5, 8, 6, 6**; B: **2, 3, 3, 3, 3**.
Порог активности не определяет строгую размерность представления: для seed 101 у B две активные оси,
но R²=0,951. Слабые координаты ниже порога всё ещё могут нести извлекаемую регрессией информацию.
Улучшение интерполяции и сэмплов из исходной гипотезы не подтвердилось.

4096 обучающих и 1024 тестовых синтетических RGB-сцен 32×32; seed данных 7.
ConvVAE, d=8; Adam, lr=0.002; batch=128; **30 эпох / 960 обновлений** на модель.
Разогрев веса KL-члена до β в течение первых 10 эпох.

Основная серия: 10 моделей (A/B × 5 seed). Дополнительно: AE с β=0, seed 101;
пять моделей β=1 без разогрева. Модели A повторно используются в сравнении разогрева.
Всего **16 измеряемых обучений**. Каждая модель сохранена в NPZ без pickle.

Фактическая среда: **Windows CPU float32, четыре потока**. Engee и Julia не использовались.
Библиотека lab08_lib.py восстановлена из приложения А PDF: исправлены разрывы строк, алгоритмы сохранены.
Исходный файл автора не предоставлен; совпадение с его контрольной суммой не заявляется.
lab07_lib.py скопирован из ЛР07 без изменения; сама папка ЛР07 не менялась.

До обучения записаны гипотеза и допуски: **PSNR ±1 дБ; R² ±0.05**.
Метрики: реконструкция 1024 тестовых сцен; интерполяция 200 пар × 3 точки (seed 11);
256 сэмплов из N(0,I) с seed=1000+seed обучения; R² линейного восстановления факторов по μ.
Средний PSNR рассчитывается по изображениям, а не через среднюю MSE всего набора.

Критерий активности оси: средний тестовый KL_j > 0.05 нат. Разброс μ: std с ddof=1.
У AE голова logvar не обучается; её KL не используется для вывода об активности осей.
s в таблице - выборочное стандартное отклонение режима A; Δ=B−A.
Правило |Δ|>2s - учебная эвристика, не формальный статистический тест.
Все четыре метрики могут изменяться при β; контрольных метрик с точным Δ=0 у этого фактора нет.

## Повторное выполнение

Python 3.11 или совместимый. Из папки LR08:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src/build_notebook.py
.\.venv\Scripts\python.exe src/verify_artifacts.py
```

`build_notebook.py` создаёт и **выполняет все обучения** в блокноте. Jupyter требует локального соединения
с ядром Python. После установки зависимостей интернет для вычислений не нужен.
Альтернатива без Jupyter: `python lab08_demo.py` (тоже полное обучение и проверка).
Повторное выполнение перезапишет результаты и веса. Предварительная регистрация не перезаписывается;
для нового эксперимента сохраните прежнюю регистрацию вместе с предыдущими результатами.

Для Engee загрузите эту папку; минимальный запуск из Julia:
