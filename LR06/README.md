## Что зафиксировано

Модель `stabilityai/sd-turbo`, ревизия `b261bac6fd2cf515557d5d0707481eafa0485ec2`.
CLIP `openai/clip-vit-base-patch32`, ревизия `3d74acf9a28c67741b2f4f2ea7635f0aaf6f0268`.
512 × 512, guidance 0,0, свежий CPU Generator на каждый вызов, один неизменный английский запрос.
Веса генератора - вариант fp16, вычисления - float32. Внимание PyTorch SDPA, attention slicing отключён.

Допуски до запуска: CLIP ±1,0 пункта, границы и контраст ±10%, время ±20% среднего A.
CLIP всегда сравнивает изображение с исходным английским брифом. Собель реализован в NumPy:
та же нормировка 1/8 и отражение на границах, что у `scipy.ndimage.sobel(mode='reflect')` из методички.
Прогрев обоих режимов выполняется на seed 0; измеряемая серия чередует A и B для каждого seed.
Время относится только к вызову генератора, без CLIP, сохранения PNG и загрузки весов.


Фактический запуск в этом репозитории использовал уже установленную среду `../LR05/.venv` и ранее загруженный
закреплённый снимок SD-Turbo из `../LR05/.cache`. Сами материалы LR05 не изменяются.
При отсутствии этого снимка библиотека скачивает ту же ревизию в локальный кэш LR06.
Для CLIP загрузчик проверяет размер диапазонов и полную SHA-256 весов по Git LFS закреплённой ревизии.
Первый запуск требует нескольких гигабайт весов. Перезапуск генератора перезаписывает гипотезу и результаты;
сначала сохраните текущую папку для сравнения разных сеансов.

`build_notebook.py` действительно выполняет ячейки анализа и повторно считает CLIP по десяти PNG.
Исходная генерация выполнялась отдельным скриптом и зафиксирована в журнале. В блокноте доступна
ячейка `RUN_FULL_EXPERIMENT=True` для нового полного запуска после загрузки CLIP.
Чтение уже выполненного блокнота не требует установки моделей.

## Ограничения

Один бриф, одна модель, пять seed. Критерий 2s - учебная эвристика разброса, не p-тест.
Рост энергии границ и контраста не доказывает эстетического улучшения. Время зависит от фоновой нагрузки.
Числа GPU из методички используются только для сопоставления и явно отделены от собственных измерений.
768 × 768, другой бриф, новый сеанс и GPU в этой работе не проверялись.
