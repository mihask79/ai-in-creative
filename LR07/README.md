## Фактический результат основной серии

| Метрика | A: d=8 | B: d=2 | Δ=B−A | По допуску |
| --- | ---: | ---: | ---: | --- |
| PSNR на тесте, дБ | 25,7587 | 23,1734 | −2,5853 | ухудшение |
| Разрыв train-test, дБ | 0,04031 | 0,09294 | +0,05263 | нейтрально |
| Параметры, тыс. | 101,035 | 88,741 | −12,294 | снижение на 12,17% |
| Время, с | 24,5608 | 24,7470 | +0,1862 | нейтрально |

Средняя картинка даёт **17,1707 дБ**; выигрыш A **8,5880 дБ**, B **6,0027 дБ**.
Для PSNR |Δ|/s=3,044: эффект превышает и 2s, и допуск 1 дБ.
Для разрыва |Δ|/s=4,319: критерий 2s срабатывает, но изменение остаётся в допуске 0,1 дБ.
Это конкретный пример различия устойчивости эффекта по seed и его практической величины.
У режима B визуально сильнее выравнивается радиус дисков; положение сохраняется приблизительно.
Время CPU практически одинаково; сокращение числа весов не гарантирует ускорения всей сети.

## Условия эксперимента

Фактическое выполнение: локальный Windows, **CPU float32, четыре потока**, без Colab T4.
Использована библиотека из приложения А PDF; исправлены переносы строк при извлечении, вычисления сохранены.
Исходная контрольная сумма файла автора методички не заявляется: доступен PDF, а не исходный `.py`.

4096 обучающих и 1024 тестовых сцен, 3×32×32, значения 0…1.
Диск задаётся тремя независимыми параметрами: x, y и радиусом.
Архитектура: Conv 3→16→32→64, Linear 1024→d; Linear d→1024 и транспонированные свёртки 64→32→16→3.
Потери MSE, Adam, lr=0.002, batch=128, **20 эпох / 640 обновлений** для каждой модели.

До обучения записаны допуски: **PSNR ±1 дБ, разрыв train-test ±0,1 дБ, время ±20%**.
PSNR - среднее по изображениям тестовой выборки; разрыв считается по первым 1024 обучающим и всем 1024 тестовым сценам.
Выборочное s вычислено по режиму A, ddof=1; Δ=B−A. Критерий |Δ|>2s - учебная эвристика, не формальный тест.
Для параметров s=0, отношение не определено; изменение числа весов детерминировано.

Время включает построение модели, оптимизатор и обучение, как в L.run методички; данные, оценка и сохранение исключены.
Один полный прогрев A (seed 0) исключён из статистики. Основная серия чередует A и B для каждого seed.
Диагностика d=1,2,3,4,8 проведена по seed 101–103. Шесть результатов d=2 и d=8 переиспользованы;
всего **19 измеряемых обучений и один прогрев**.

## Повторное выполнение

Из папки LR07, Python 3.11 или совместимый:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src/build_notebook.py
.\.venv\Scripts\python.exe src/verify_artifacts.py
.\.venv\Scripts\python.exe src/lab07_report.py
.\.venv\Scripts\python.exe src/package_results.py
```

`build_notebook.py` создаёт блокнот и **действительно выполняет все обучения** внутри его ячейки.
Повторный запуск перезапишет веса и результаты. Для новой регистрации условий переместите прежний
`configs/preregistration.json` вместе с предыдущими результатами; существующий файл сохраняется как исходная запись.
Jupyter требует локального соединения с ядром Python. Интернет во время эксперимента не требуется.

Локально использована уже установленная среда `../LR05/.venv`; отчёт собран штатной средой PDF.
Полный список пакетов обучающей среды сохранён в requirements-lock.txt; часть пакетов относится к предыдущим работам.
Отчёт пересобирается после наличия `artifacts/visual_review.json` с проверенными наблюдениями.
После повторного обучения визуальную оценку нужно выполнить заново, затем обновить отчёт и архив.

Десять весов сохранены в NPZ без pickle, по одному файлу на модель; проверки восстанавливают модели и заново считают PSNR.
SHA256SUMS.txt покрывает файлы архива, кроме самого списка и ZIP. В архив не включены локальные среды и кэш.
