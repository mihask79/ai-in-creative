# Лабораторная работа 3 — вариант 1

Подготовка изображений и визуализация: базовая сцена с градиентом и кругом и квантование яркости до 4 бит.

## Запуск

Из папки `LR03`:

```powershell
python -m pip install -r requirements.txt
python src/lab03_experiment.py
python src/lab03_report.py
```

Скрипт сохраняет исходное и обработанное изображение, гистограммы, график сравнения метрик, результаты по каждому seed, сводку и паспорт эксперимента в `artifacts/`. В `reports/` создаётся отчёт по структуре методички с фактическими результатами Python и указанием ограничения по Engee.

## Параметры

- Вариант: 1.
- Сцена: градиент и круг, средний контраст; lo=0,15, hi=0,85, шум 0,02.
- Воздействие: квантование яркости до 4 бит (16 уровней).
- Seed: 101–105; гистограмма: 32 интервала.
- Практический допуск задан до запуска: относительное изменение метрики >5% или PSNR <30 дБ.
- Статистическое правило: `|разность средних| / s_исходного > 2`.

## Ограничение реализации

Файл `lab03_lib.jl` из материалов курса не был приложен. Поэтому генератор сцены реализован на Python по текстовым параметрам методички: градиент и круг с шумом, зависящим от seed. Это воспроизводимый учебный эквивалент, но не побитовое воспроизведение Engee или исходной библиотеки. Для точного совпадения чисел замените `make_scene` и преобразование яркости на реализации из `lab03_lib.jl`.
