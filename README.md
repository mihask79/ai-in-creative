## Лабораторная работа № 2

Вариант 7 рассматривает публикацию монетизируемых обложек подкастов. В `LR02-variant07/` находятся скрипты генерации учебного манифеста, проверки лицензий, подготовки карточки модели и валидации реестра рисков, а также входные данные и отчёты. Для запуска команд и описания синтетических данных см. [README работы](LR02-variant07/README.md).

```text
LR02/
├── src/        скрипты генерации данных, аудита и проверки рисков
├── artifacts/  манифест, политика, паспорт ЛР 1 и реестр рисков
├── reports/    DOCX-отчёт, паспорт набора, карточка модели и результаты проверок
└── README.md   описание и команды запуска
```

Выполненная проверка реестра рисков завершилась `RESULT: PASS`. Манифест содержит синтетические учебные записи; выводы по лицензиям не заменяют проверку первоисточников и юридическую оценку.

## Правила ведения работ

1. Записывать параметры, версии среды и команду запуска.
2. Фиксировать seed и проверять воспроизводимость по полным данным.
3. Хранить результаты эксперимента и контрольные суммы рядом с отчётом.
4. Отрицательные результаты и ограничения указывать явно.
5. Не включать веса моделей и локальные виртуальные среды в архивы.
