# Искусственный интеллект в креативных технологиях

Лабораторные работы курса. Каждая работа — один Jupyter-ноутбук, в котором
подряд идут код, фактические выходы его выполнения и отчёт, плюс полученные
артефакты с манифестами.

## Работы

| № | Тема | Вариант | Ноутбук | Результат |
| --- | --- | --- | --- | --- |
| 01 | Запуск открытой модели text-to-image | 3 — концепт постера научной выставки | [LR01.ipynb](LR01/LR01.ipynb) | два запуска, SHA-256 совпали |

## Как это устроено

```text
LR0N/
├── LR0N.ipynb      код + сохранённые выходы + отчёт
├── README.md       что это и как повторить
├── assignment/     методические указания
├── configs/        параметры запуска одним файлом
├── artifacts/      результаты: файл + manifest.json рядом
└── reports/        environment.txt и сравнения
```

**Правила, которые соблюдаются во всех работах:**

1. Все параметры эксперимента находятся в одном конфиге.
2. Рядом с результатом лежит `manifest.json` с моделью, полной ревизией,
   prompt, seed, параметрами, средой и SHA-256.
3. Веса модели и виртуальное окружение не коммитятся.
4. Отрицательный результат и воспроизведённая ошибка фиксируются, а не скрываются.
5. Сохранённые выходы ноутбука служат проверяемым протоколом выполнения.
