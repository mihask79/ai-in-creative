# Искусственный интеллект в креативных технологиях

Репозиторий содержит лабораторные работы курса. Для каждой работы здесь хранятся исходный код или ноутбук, параметры эксперимента, фактические результаты и отчёт.

## Работы

| Папка | Работа | Вариант | Основные материалы |
| --- | --- | --- | --- |
| [`LR01/`](LR01/README.md) | Запуск открытой модели text-to-image | 3 — концепт постера научной выставки | [Ноутбук](LR01/LR01.ipynb), изображения, манифесты и сведения о среде |
| [`LR01-01/`](LR01-01/README.md) | Подготовка среды и паспорт воспроизводимого AI-эксперимента | 7 — бумажная текстура, размер 96 → 144 | [Отчёт и паспорт](LR01-01/reports/ЛР01_Отчет_и_паспорт.docx), [архив материалов](LR01-01/artifacts/lr01_variant07_artifacts.zip), [результаты JSON](LR01-01/artifacts/results.json) |

## Структура лабораторной работы

```text
LR01-01/
├── src/             генератор, эксперимент и демонстрация seed
├── artifacts/       изображения, результаты и архив материалов
├── reports/         отчёт с паспортом и журнал выполнения
├── requirements.txt сторонние зависимости (для варианта 7 не требуются)
└── README.md        параметры и команды запуска
```

Чтобы повторить вариант 7, откройте `LR01-01/README.md`. Виртуальная среда `.venv` локальная и в архив не включается; её можно создать командой `python -m venv .venv`.

## Правила ведения работ

1. Записывать параметры, версии среды и команду запуска.
2. Фиксировать seed и проверять воспроизводимость по полным данным.
3. Хранить результаты эксперимента и контрольные суммы рядом с отчётом.
4. Отрицательные результаты и ограничения указывать явно.
5. Не включать веса моделей и локальные виртуальные среды в архивы.
