# Лабораторная работа 5 — вариант 1

Запуск открытой модели text-to-image и проверка повторяемости в одном сеансе.

- Бриф: афиша фестиваля робототехники, синий и янтарный, силуэт механической руки.
- Условие: повтор со свежим генератором и тем же seed.
- Модель: `stabilityai/sd-turbo`, ревизия `b261bac6fd2cf515557d5d0707481eafa0485ec2`.
- Seed: `1001`; один шаг; `guidance_scale=0.0`; `512 × 512`.
- Фактическая среда: Windows, локальный Python, CPU, float32, один поток PyTorch.
- Веса загружаются из варианта `fp16` закреплённого снимка и приводятся к float32 для вычислений.
- Допуск записан до запуска в `configs/preregistration.json`: одинаковые пиксели — `identical`, иначе PSNR ≥ 40 дБ — `close`, ниже — `different`.

## Повторный запуск

Команды из папки `LR05` (Windows PowerShell, Python 3.11):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src/lab05_experiment.py
```

Для повторного выполнения блокнота со всеми выводами:

```powershell
.\.venv\Scripts\python.exe src/build_notebook.py
```

Скрипты перезаписывают результаты и запись гипотезы при новом запуске. Сначала сохраните текущие материалы, если хотите сравнивать разные сеансы. Для чтения уже выполненного блокнота запуск не нужен. При первом запуске понадобится загрузить несколько гигабайт весов. `.cache/` и `.venv/` не входят в сдаваемый архив.

Проверка сохранённых результатов без загрузки модели:

```powershell
.\.venv\Scripts\python.exe src/verify_artifacts.py
```

Для пересборки PDF нужен `reportlab`; скрипт `src/lab05_report.py` читает готовые результаты и визуальную оценку. В этой работе отчёт собран встроенной средой документов Codex. При переносе на другую ОС нужно заменить путь к Arial в скрипте.

## Границы вывода

Это фактический локальный эксперимент Python. Engee и Google Colab не использовались. Проверка относится к одному сеансу, одному seed и CPU float32. Совпадение в новой сессии, на GPU или с другими версиями не заявляется. Количественные результаты находятся в JSON и отчёте; SHA-256 и метрики в блокноте повторно рассчитаны по сохранённым PNG.
